# Lecture 05: herramientas externas y MCP

## Propósito de esta sesión

- Comprender cómo separar las herramientas de un agente de las funciones internas de la aplicación para ofrecerlas como «servicios externos»
- Experimentar cómo MCP (Model Context Protocol) permite compartir herramientas entre distintos clientes

## Puntos clave

1. **Herramientas externas**: funciones externas al agente, como obtener páginas web, operar sobre archivos, consultar bases de datos o llamar a API de terceros. Las herramientas de función de Lecture 03 estaban en el mismo proceso, mientras que las externas se llaman entre procesos o máquinas diferentes.
2. **Papel de MCP**: protocolo común entre quien ofrece las herramientas (servidor MCP) y quien las usa (cliente MCP: un agente o editor). Un servidor puede utilizarse con el mismo procedimiento desde cualquier cliente compatible.
3. **Qué ofrece el servidor**: nombres, descripciones y esquemas de argumentos de las herramientas. El modelo los lee para decidir las llamadas. Recibe desde otro proceso la misma información que proporcionaban los docstrings de Lecture 03.
4. **Transporte**: con stdio, el cliente inicia el servidor como subproceso e intercambia mensajes mediante la entrada y la salida estándar. Con Streamable HTTP, el servidor escucha en una URL y también admite conexiones desde otras máquinas.
5. **Servidores ya existentes**: basta con añadir los servidores públicos de archivos, obtención de páginas web (fetch), GitHub, etc., al archivo de configuración (formato mcpServers). El usuario es responsable de los permisos que concede (escritura de archivos, envío de datos al exterior).
6. **Espacios de nombres y coste**: los nombres de herramientas de varios servidores se distinguen con «nombre_del_servidor_nombre_de_herramienta». Cuantas más herramientas haya, más descripciones recibe el modelo, lo que afecta a la precisión al elegir herramientas y al número de tokens por llamada.
7. **Seguridad**: los servidores MCP ejecutan código arbitrario. No configures servidores de procedencia desconocida. Si los expones mediante HTTP, considera la autenticación y el alcance de acceso (el reenvío de puertos de Codespaces es privado de forma predeterminada).

## Qué experimentarás en los ejercicios

- Exponer las herramientas del glosario de Lecture 03 mediante un servidor MCP y usarlas desde el mismo agente a través de MCP
- Exponer una herramienta
- Añadir un servidor fetch ya existente con solo modificar el archivo de configuración
